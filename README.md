# Anas Butt

I am an AI engineer and technical founder building specialized AI workers for real business workflows. I founded [Omniveer](https://www.omniveer.com), where I design, deploy, and manage focused AI systems that connect with existing tools, operate within clear rules, and hand control back to people when it matters. Our first product, [Duct Lead Qualifier](https://www.omniveer.com/duct-lead-qualifier), handles inbound conversations for duct-cleaning businesses, captures job details, delivers qualified leads, and keeps every interaction visible for review.

My open-source work explores how to make AI agents more useful, observable, and safe to operate. I built [AgentReplay](https://github.com/anusbutt/agent-replay), a flight recorder and time-travel debugger that captures agent runs, finds failures, and lets developers test fixes against the original context without repeating real-world side effects. I developed it solo for the AMD Developer Hackathon ACT II, using a Python SDK, FastAPI, PostgreSQL, Next.js, and a provider-swappable LLM analysis layer.

I also created [Prospector](https://github.com/anusbutt/Prospector), a research and outreach pipeline that produces source-cited drafts and sends only what a person approves. [Nestaro Pilot](https://github.com/anusbutt/nestaro-pilot) extends the same human-in-the-loop approach across Gmail, WhatsApp, social channels, and Odoo through Claude Code, skills, and MCP integrations. Other projects include [Commit Voice](https://github.com/anusbutt/commit-voice), which turns GitHub activity into reviewable social posts, and [TaskMate](https://github.com/anusbutt/taskmate), a conversational task manager built with MCP tools, FastAPI, Next.js, and PostgreSQL.
