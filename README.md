## Omniveer

I’m building [Omniveer](https://www.omniveer.com), a company that builds, deploys, and manages specialized AI workers for real businesses. The focus is straightforward: automate useful work, fit into existing operations, and keep people in control.

### Duct Lead Qualifier

[Duct Lead Qualifier](https://www.omniveer.com/duct-lead-qualifier) helps duct-cleaning businesses handle incoming leads without losing the human handoff. It can:

- respond to new inquiries and ask qualification questions;
- capture customer details and email qualified leads to the business owner;
- save lead data and chat transcripts in a dashboard; and
- keep a human in control of the workflow.

## Selected work

- **[Prospector](https://github.com/anusbutt/Prospector)** — A Python CLI that researches local service businesses and creates sourced, personalized outreach drafts in an Obsidian vault. Sending is dry-run by default and limited to human-approved drafts.
- **[Agent Replay](https://github.com/anusbutt/agent-replay)** — A flight recorder and debugger for AI agents, with a Python SDK, FastAPI backend, and Next.js dashboard for inspecting failures and testing fixes with sandboxed tool calls.
- **[Commit Voice](https://github.com/anusbutt/commit-voice)** — A Next.js application that turns GitHub commit activity into draft posts for X and LinkedIn, with a review-and-approval workflow before publishing.
- **[Physical AI & Humanoid Robotics Textbook](https://github.com/anusbutt/Physical-AI-Humanoid-Robotics-Textbook)** — An interactive Docusaurus learning platform with a FastAPI RAG assistant grounded in the textbook’s content.
- **[TaskMate](https://github.com/anusbutt/taskmate)** — A full-stack task manager that uses Next.js, FastAPI, PostgreSQL, and MCP tools to support task CRUD through natural-language chat.
